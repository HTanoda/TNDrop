# TNDrop 手動テストチェックリスト (v1.0.0 / v1.1.0 / v1.2.0)

配布前の最終確認用。仕様書 §3 の全機能を「操作 → 期待結果」形式で列挙する。
各行を実施したら結果欄に `PASS` / `FAIL` と実施日、気づいた点を記入すること。

必須項目 (配布ブロッカー) には **[必須]** を付けている。それ以外は不具合があってもリリース判断はユーザー相談。
