- **表示仕様**: 画像/動画ファイルの単独カードは既存 Image カードと同様の**大サムネイル** (カード幅いっぱい、高さ上限あり) + ファイル名キャプション。非メディアファイルは左端スロットにシェル拡張子アイコン (32px 論理)。

### Task A: ShellImaging サービス (シェルサムネイル・アイコン取得)

**Files:**
- Create: `src/TNDrop.App/Platform/ShellImaging.cs`
- Create: `src/TNDrop.App/Core/MediaKind.cs` (純粋分類ヘルパー)
- Test: `src/TNDrop.Tests/MediaKindTests.cs`

**Interfaces:**
```csharp
namespace TNDrop.Core;
public enum MediaCategory { Image, Video, Other }
public static class MediaKind
{
    public static MediaCategory Classify(string path); // 拡張子のみで判定、大文字小文字無視。上記 Global Constraints の拡張子リスト
}

namespace TNDrop.Platform;
public static class ShellImaging
{
    // IShellItemImageFactory.GetImage で取得。thumbnailPx 論理 96dpi 基準。
    // SIIGBF_THUMBNAILONLY→失敗時 SIIGBF_ICONONLY フォールバック。HBITMAP は
    // Imaging.CreateBitmapSourceFromHBitmap → 必ず DeleteObject。Freeze() して返す。
    // 失敗は null (type-only Warn、パスはログに書かない)。
    public static ImageSource? GetThumbnail(string path, int px);   // 大サムネ用 (256)
    public static ImageSource? GetIcon(string path, int px);        // 拡張子アイコン用 (32)
    // LRU キャッシュ: アイコンは拡張子キー (フォルダは固定キー)、サムネはフルパス+更新時刻キー。上限 128。
}
```
- TDD: MediaKind.Classify のテスト (画像各種 / 動画各種 / .xlsx→Other / 大文字 .PNG / 拡張子なし)。ShellImaging はビルド+プローブ検証 (実ファイルでサムネ取得、HBITMAP リーク無しは GDI ハンドル数で確認)。
- [ ] テスト→RED→実装→GREEN→プローブ→コミット `feat: shell thumbnails and icons service`
