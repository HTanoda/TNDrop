# TNDrop v1 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 画面端ホバー表示 / コピー自動キャプチャ / ドラッグ&ドロップ / スタック / ピン / 検索 / プライバシー保護を備えたクリップボード・シェルフを WPF ネイティブで実装し、オフライン庁内 PC にユーザー単位インストールできる形で配布する。

**Architecture:** 単一プロセス・トレイ常駐の WPF アプリ。Core (モデル・永続化) / Platform (Win32 相互運用) / Services (ログ・音・自動削除) / UI (シェルフ・設定) の 4 層。クリップボード監視はイベント駆動 (`AddClipboardFormatListener`)、エッジ検知はグローバルフックなしの透明トリガーウィンドウ方式。

**Tech Stack:** .NET 10 (LTS) / WPF / WinForms NotifyIcon (トレイのみ) / xUnit / System.Text.Json / System.Security.Cryptography.ProtectedData (DPAPI) / Inno Setup 7

## Global Constraints

- 仕様書: `docs/superpowers/specs/2026-08-20-tndrop-v1-design.md` (承認済み。矛盾したらこの計画ではなく仕様書が正)
- TargetFramework: `net10.0-windows`、`RuntimeIdentifier win-x64`、self-contained 配布
- **外部通信は一切書かない** (HTTP クライアント・更新チェック・テレメトリ・ファビコン取得すべて禁止)
- NuGet 依存は `System.Security.Cryptography.ProtectedData` と `xunit`/`xunit.runner.visualstudio`/`Microsoft.NET.Test.Sdk` (テストのみ) に限定。UI フレームワーク・MVVM ライブラリ・ログライブラリは追加しない
- ソースは UTF-8 (BOM なし) / LF。`.iss` は UTF-8 BOM / CRLF (Task 18)
- ログ形式: `logs/app-YYYYMMDD.log`、`YYYY-MM-DD HH:MM:SS [LEVEL] module: メッセージ`。**クリップボードの内容・個人情報をログに書かない**
- エンドユーザーにスタックトレースを見せない。利用者向け文言は日本語
- 配布物・ソースのファイル名に日本語を使わない
- 著作権表記: `Copyright (c) 2026 HIROKI TANODA (TND). All rights reserved.`
- コミットは各タスク末尾で行う (この計画のユーザー承認をもって明示指示とみなす。push はしない)
- ビルド/テストは PowerShell から `dotnet` CLI で実行

public class ItemStorePersistenceTests : IDisposable
{

    public void Dispose() { try { Directory.Delete(_dir, true); } catch { } }

    private static ClipItem TextItem(string text) => new()
    {

        ContentHash = ItemStore.Fnv1a(System.Text.Encoding.UTF8.GetBytes(text))

    public void Save_then_load_roundtrips_items()
    {
        var store = new ItemStore(_dir);
        store.TryAdd(TextItem("hello"));
        store.Save();
        var store2 = new ItemStore(_dir);
        store2.Load();
        Assert.Single(store2.Items);
        Assert.Equal("hello", store2.Items[0].Text);
        Assert.False(store2.LoadFailed);

    [Fact]
    public void Saved_file_is_not_plaintext()
    {

        store.TryAdd(TextItem("SECRETWORD"));
        store.Save();
        var raw = File.ReadAllBytes(Path.Combine(_dir, "items.dat"));
        Assert.DoesNotContain("SECRETWORD", System.Text.Encoding.UTF8.GetString(raw));

    public void Load_recovers_from_bak_when_dat_corrupt()

    [Fact]
    public void Load_yields_empty_and_flags_when_both_corrupt()

        File.WriteAllBytes(Path.Combine(_dir, "items.dat"), new byte[] { 1 });
