### Task A: フッターのファイル数化 + resx 整合テスト + ログ修正

- ShelfViewModel: フッターの「全 N 件」(VisibleCount 経由の表示) をバッジと同じ寄与規則 (Contribution: スタック=Paths.Count、他=1) で数える。**選択件数 (選択 N 件) はカード数のまま変更しない** (選択操作の単位はカードのため)。件数の解決は既存 Contribution ヘルパーを再利用し第 2 の数え方を作らない。フッターとバッジが常に同じ母数になることをテストで固定。
- resx 整合の自動テスト: Strings.resx / Strings.en.resx のキー集合が一致し、かつ両方が Strings.cs ラッパーのプロパティ集合と一致することを検証するテストを追加 (resx は XML なのでテストから直接パース可能)。
- ItemStore.cs DeleteBlobIfPresent (~:627) の Warn ログから fileName と ex.Message を除去し、隣接箇所と同じ ex.GetType().Name のみに (v1.3 規約準拠)。
- テスト: フッター件数 (単独/スタック/混在、グループ化往復で不変) / resx 整合 / 全緑。

### Task B: フォーカス枠のダーク対応 (SettingsWindow)

- SettingsWindow の Tab フォーカス枠 (FocusVisualStyle) が OS ライトテーマで黒破線になり視認不能な件。ダーク背景で見える明示色 (例: 白系 1px 破線 or アクセント色) の FocusVisualStyle を定義し、設定画面のフォーカス可能コントロール (CheckBox/RadioButton/ComboBox/Slider/ナビボタン) に適用。SystemColors 依存を排除。
- 検証: プローブで Tab 巡回のスクリーンショット (フォーカス枠が各コントロールで視認できること)。既存のキーボード操作 (Tab 順・Space/Enter) を壊さない。
