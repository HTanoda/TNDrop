- 既存の同種ツール 参考にした外部 LP の文言・画像は複製しない (構成の参考のみ)

### Task A: README.html 制作

- `assets/README.html` を新規作成 (設計書の構成・デザイン要件どおり)。frontend-design + apple-design スキルを読み込んで制作すること。
- ヒーローのアイコンは D:\TNDrop\TNDrop.png を 256px 程度に縮小した PNG を data URI 埋め込み。機能セクションのビジュアルは CSS/SVG アニメのモックアップ主体 (シェルフのスライドイン、カードのスタック/展開、ドラッグの軌跡等)。実スクショを使う場合は一時ストアのプローブで撮影。
- prefers-reduced-motion で全アニメ停止。ページ内スクロール以外の JS 依存は最小 (JS ゼロでも成立する構成が望ましい)。
- 検証: ブラウザで file:// 表示のスクリーンショット (全セクション) / ファイルサイズ ~1MB 以下 / grep で http(s):// 参照ゼロ (data URI と xmlns を除く)。
- このタスクではアプリ本体・csproj に触らない (Task B の範囲)。
