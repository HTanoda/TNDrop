### Task A: ShutdownSignal (アプリ側の終了要求待ち受け)

- `src/TNDrop.App/Platform/ShutdownSignal.cs` 新規: `ShutdownSignal(string eventName, Action onSignaled)` — `new EventWaitHandle(false, EventResetMode.AutoReset, eventName)` + `ThreadPool.RegisterWaitForSingleObject`。コールバックはワーカースレッドで呼ばれる契約 (Dispatcher マーシャリングは呼び出し側)。`IDisposable` で `Unregister` + ハンドル破棄。Dispose 後は発火しない。
- App.xaml.cs: 定数 `ShutdownRequestEventName = "Local\\TNDrop_ShutdownRequest"`。OnStartup の単一インスタンス勝者確定後 (Mutex 判定分岐より後、(2) 以降) に `new ShutdownSignal(ShutdownRequestEventName, () => Dispatcher.BeginInvoke(Shutdown))` を保持。OnExit で Dispose。Info ログ 1 行 (「shutdown requested by installer」等、パス等なし)。
- テスト (TNDrop.Tests): 一時イベント名で ShutdownSignal を作成 → 別 `EventWaitHandle.OpenExisting` から Set → コールバック発火を ManualResetEventSlim 等で待って assert (タイムアウト付き)。Dispose 後に Set → 発火しないこと。二重 Dispose 安全。
- 検証: `dotnet test` 全緑 (312 + 新規)。
