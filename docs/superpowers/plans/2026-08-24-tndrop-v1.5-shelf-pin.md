**Goal:** シェルフヘッダーの設定ボタン左隣にピン止めトグルを追加し、ピン中は自動格納を抑止する (v1.5.0 のまま、バージョン変更なし)。

**Tech Stack:** .NET 10 WPF、xunit。新規 NuGet 依存なし。

**正となる設計書:** `docs/superpowers/specs/2026-08-24-tndrop-v1.5-shelf-pin-design.md`

メソッド 2 つを `OnHelpButtonClick` の近くに追加:

```csharp
    private void OnPinButtonClick()
    {
        _pinned = !_pinned;
        global::TNDrop.App.SetShelfPinned(_pinned);
        UpdatePinButtonVisual();

        if (_pinned)
        {
            _retractTimer.Stop();
        }
        else
        {
            ArmRetractIfPointerOutside();
        }
    }

    /// <summary>ピンボタンのオン/オフ表示 (v1.5 追補)。ピン中はグリフを E840 (pinned) +
    /// アクセント色にし、うっすら固定背景でトグルのオン状態を常時見せる。ホバー時は
    /// Header.IconButtonStyle のテンプレートトリガーが背景を上書きするので、ここで設定する
    /// Background は非ホバー時の土台だけを受け持つ。</summary>
    private void UpdatePinButtonVisual()
    {
        HeaderPinButton.ToolTip = _pinned ? Strings.HeaderPinActiveTooltip : Strings.HeaderPinTooltip;
        HeaderPinIcon.Text = _pinned ? "\uE840" : "\uE718";
        HeaderPinIcon.Foreground = _pinned
            ? (System.Windows.Media.Brush)FindResource("Card.SelectedAccent")
            : (System.Windows.Media.Brush)FindResource("Card.Foreground");
        HeaderPinButton.Background = _pinned
            ? new System.Windows.Media.SolidColorBrush(
                System.Windows.Media.Color.FromArgb(0x22, 0xFF, 0xFF, 0xFF))
            : System.Windows.Media.Brushes.Transparent;
    }
```

`ApplySettings` の `_pinned = s.ShelfPinned;` (Task A) の直後に `UpdatePinButtonVisual();` を追加。ただし ApplySettings がコンストラクタ内で InitializeComponent より後に呼ばれることを確認すること (XAML 要素が null の段階で呼ぶと NRE。呼び順が逆なら `HeaderPinButton is null` ガードではなく呼び出し位置で解決する)。型の完全修飾は既存ファイルの using と衝突しない範囲で省略してよい (System.Windows.Media が using 済みなら短縮形に直す)。
