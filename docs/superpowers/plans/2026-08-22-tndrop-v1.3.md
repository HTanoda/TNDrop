# TNDrop v1.3 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Tasks A→G 直列。

**Goal:** フィードバック第 3 弾 (v1.3.0)。設計: docs/superpowers/specs/2026-08-22-tndrop-v1.3-design.md (以下「設計書」。各タスクの詳細仕様はここを正とする)

## Global Constraints

- 外部通信禁止 / NuGet 追加禁止 / UTF-8 no BOM LF (.iss は BOM CRLF) / ログにパス・クリップボード内容・ファイル名禁止 (理由コードのみ) / XAML コメント `--` 禁止 / resx は ja+en+ラッパー (Strings.resx / Strings.en.resx / Strings.cs) 同時 / 各タスクでテスト全緑 (現在 315) / コミット末尾 Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>
- 実プロファイル (%APPDATA%\TNDrop) に触る検証禁止 / 実クリップボード禁止 (インストール済み TNDrop.exe 稼働中の可能性) / プローブは一時ストア + `dotnet run` 経由 (framework-dependent exe 直接起動禁止)
- UI を触るタスク (C/D/E) の実装者・レビュアーは apple-design スキルを読み込むこと

### Task A: バッジ件数のファイル数化

- ShelfViewModel: カード寄与 = `IsStack ? Paths.Count : 1` を 1 つのヘルパーにし、全 5 バッジ (すべて/テキスト/リンク/画像/ファイル) を同じ寄与関数×同じ分類ヘルパー (IsImageEntity 等) から導出。フィルタ表示 (MatchesFilter) はカード単位のまま不変。
- テスト: 単独カード各種=1 / 全画像スタック 3 件→画像に 3 / 混在スタック→ファイルに Paths.Count / CountAll=サブ合計不変条件 / グループ化・解除操作の前後で合計が変わらないこと。

### Task B: クリップボード画像のグループ化

- ItemStore: 画像カード (Kind=Image) がマージ対象になった時点で blob PNG を指す Kind=Files 単一カードへ変換 (`ConvertImageToFileCard` 等)。ファイル名はドラッグアウトの既存命名関数を再利用 (grep で特定し、共通関数化。one-resolution)。ピン・CreatedAt 維持。変換後は既存 TryMergeFiles に乗せる。
- ShelfWindow.ResolveMerge / DragDropTarget.IsCardMergeDrag: 画像カードをマージ候補に含める (画像→ファイルカードへのドロップ、ファイル→画像カードへのドロップ、画像→画像)。
- 削除時の blob 掃除: blobs\ 配下パスを参照するファイルカードの削除で当該ファイルも削除 (既存 DeleteBlobsFor の拡張。blobs\ 外のパスは絶対に消さない)。
- テスト: 変換の属性維持 / 画像+画像→2 件スタックが「画像」分類 / 削除で blob 消滅・外部ファイル不変 / ピン継承。

### Task C: フライアウト改修 + 解除 UI + 拒否ログ

- ItemStore: `SplitAll(stackId)` — 全パスを個別カードへ (ピンは全子へ継承、先頭は既存カード再利用可)。件数セマンティクスは Task A の寄与規則で不変。
- StackFlyout: ヘッダー行 (「ファイル N 件」+ グループ解除ボタン) / 各行ホバーに「1 件だけ独立」ボタン (既存 SplitRequested 経路を再利用) / 各行左に 32px サムネ (ShellImaging + 既存 LRU、画像/動画のみ。他は現行アイコン) / ScrollViewer (Scrollbars.xaml のコメント手順どおり、最大高さ制限)。resx: 解除ボタン等 ja/en。
- 帯ドラッグ判定の拒否時 Info ログ 1 行 (BeginCardDrag と flyout 行、理由コードのみ: "split refused: out-of-band" / "split refused: drop accepted")。
- テスト: SplitAll (全展開・ピン継承・blob 参照維持・10 件上限との整合) / VM 純粋部。UI はプローブ。

### Task D: ホバーアクションのピル型ツールバー化

- Cards.xaml: ピン・展開・コピー・削除をカード上端に浮かぶ濃色ピル (角丸・半透明ダーク・影・ホバー時表示) へ移動。画像/メディアカード上のオーバーレイ廃止。ドラッグ開始・クリック (貼り付け/コピー)・ダブルクリック等の既存ジェスチャを妨げないこと。apple-design 準拠 (呼応性・控えめな影・8pt グリッド)。
- 検証: プローブでカード種別ごとのスクリーンショット (白画像で視認できることを含む)。

### Task E: ピン留め境界 + インジケーター強調

- ShelfWindow.xaml: ピン留めセクションに薄い背景ティント + 下端区切り線 + ヘッダー強化。PinnedExpanded の挙動不変。
- IndicatorWindow: 4 様式共通で輝度 +30% 前後・表示時間 1.2〜1.5 倍・パルスは 1 周追加。攻撃的な点滅にしない。IndicatorEnabled ゲート不変。
- 検証: プローブ (各様式のスクリーンショット、ピン境界のスクリーンショット)。

### Task F: 設定画面の黒文字掃討 + 貼り付け抑止ログ

- SettingsWindow.xaml: OS ライトテーマで黒文字になる残存部品を総ざらいして明示色化 (CheckBox/RadioButton のグリフ+コンテンツ、ComboBox 項目、ツールチップ、Slider)。必要なら最小の ControlTemplate (v1.2 Task C の ComboBox と同様の方針、PART_ 名に注意)。
- ClickPaste 抑止時の Info ログ (理由コードのみ: self-foreground / search-focus / modifier)。
- 検証: grep で SystemColors/既定依存ゼロ + プローブスクリーンショット。テスト: ログ理由の純粋部があれば単体。
