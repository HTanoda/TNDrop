# TNDrop v1.3.1 設計: README.html + ヘルプ (?) ボタン

日付: 2026-08-22 / 対象: v1.3.1 (パッチリリース)

## 目的

一般的な LP 構成のように視覚的に分かりやすい単一ファイルの
README.html を作り、シェルフのヘッダー (歯車の隣) の「?」ボタンから開けるようにする。

## 決定事項 (ユーザー確認済み)

- ビジュアルは **CSS/SVG アニメーションのモックアップ** 方式とする。実履歴のクリアや
  実プロファイルでの録画は行わない。要所の実スクリーンショットは一時ストアのプローブで
  撮影したものを data URI で埋め込んでよい。
- 「?」ボタンは**今回実装** (v1.3.1)。言語は**日本語のみ**。

## README.html 仕様

- **単一ファイル・完全オフライン**: CDN / Google Fonts / 外部画像・JS 参照は一切禁止
  (CLAUDE.md §2.2)。CSS/JS はインライン、画像は data URI。`file://` で開いて完全動作。
  目標サイズ ~1MB 以下。フォントはシステムフォントスタック (Yu Gothic UI / Meiryo 系)。
- **構成** (一般的な LP 構成を参考に、デザインは独自):
  1. ヒーロー: アプリアイコン (TNDrop.png を縮小埋め込み) + キャッチコピー + バージョン表記
  2. 機能セクション (各セクション = 見出し + 短い説明 + CSS/SVG アニメまたはスクショ):
     ホバーで開くシェルフ / コピーで自動保存 (テキスト・画像・ファイル) / ドラッグ&ドロップ /
     グループ化 (スタックとサムネイル) / グループ解除 (フライアウトの解除ボタン・1 件独立) /
     クリックで貼り付け / ピン留め / 検索とフィルタ / スクリーンショット取り込み /
     コピーインジケーター
  3. 設定の紹介 (自動起動・履歴の容量・再起動時パージ・シークレットモード等を簡潔に)
  4. 安心情報: 完全オフライン動作・外部送信なし・データは自分の PC 内 (%APPDATA%\TNDrop、
     DPAPI 暗号化)・管理者権限不要
  5. フッター: バージョン / Copyright (c) 2026 HIROKI TANODA (TND). All rights reserved.
- **デザイン**: アプリ本体と同系のダーク基調 + アクセント (インジケーターのブランド色系)。
  frontend-design / apple-design スキルの原則に従う (タイポグラフィ階層、余白、控えめで
  上質なアニメーション、prefers-reduced-motion 対応)。参考にした LP の文言・素材はコピーしない
  (構成の参考のみ)。
- **配置**: ソースは `assets/README.html`。csproj で Content + CopyToOutputDirectory
  (PreserveNewest) にして publish 出力に含める → setup.iss は dist\publish\* を丸ごと同梱
  するため .iss 変更不要 (検証すること)。

## ? ボタン仕様

- ShelfWindow ヘッダーの歯車ボタンの隣に「?」ボタン (既存 Header.IconButtonStyle と同スタイル・
  同寸)。ツールチップは resx (ja「使い方」/ en "Help")。
- クリック → `Process.Start(new ProcessStartInfo(Path.Combine(AppContext.BaseDirectory,
  "README.html")) { UseShellExecute = true })` で既定ブラウザで開く。
- ファイル欠如・起動失敗時: 例外を握って Warn ログ (理由コードのみ) + フッターの
  ステータス表示で「ヘルプを開けませんでした」。クラッシュしない。

## リリース

- csproj / setup.iss = 1.3.1。`build.ps1` → dist\TNDrop-Setup-1.3.1.exe (実行しない)。
- checklist §25: ? ボタンで README が既定ブラウザに開く / オフライン (機内モード相当) で
  完全表示 / 全セクションの表示とアニメ動作 / インストール先の {app}\README.html 存在。

## 制約 (継承)

外部通信禁止 / NuGet 追加禁止 / UTF-8 no BOM LF (.iss は BOM CRLF) / ログにパス禁止 /
XAML コメント `--` 禁止 / resx ja+en+ラッパー同時 / テスト全緑 (現在 404) /
実プロファイル・実クリップボード禁止 / インストーラー実行禁止 / AppId 不変。
