# TNDrop v1.5 追補設計書: シェルフのピン止めボタン

日付: 2026-08-24
状態: ユーザー承認済み。v1.5.0 に含めて同バージョンで再ビルドする (バージョン番号は変更しない)。

## 背景

v1.5.0 の実機確認時のフィードバック: シェルフを自動格納させず開いたままにしたい場面が
あるため、ヘッダーの設定ボタンの隣に「ピン止め」トグルボタンが欲しい。

## 決定事項 (ブレインストーミングでの合意)

| 論点 | 決定 |
| --- | --- |
| 永続化 | 再起動後も保持 (settings.json) |
| ピン中の × / Esc | 効く (ピンは自動格納の抑止のみ。閉じてもピン状態は残る) |
| 設定画面への項目追加 | しない (ヘッダーのボタン自体が UI) |

## UI

- ヘッダーの並びを [タイトル] [ピン] [⚙ 設定] [?] [×] にする。`HeaderPinButton` を
  設定ボタンの左隣 (新しい列) に追加。
- 既存 `Header.IconButtonStyle` (Cards.xaml) を流用。アイコンは文字/絵文字ではなく
  ベクター Path のピン形にする (絵文字グリフは Foreground が効かず、オン状態の色替えが
  できないため)。Path の Fill はボタンの Foreground に追従させる。
- オン状態の常時表示: ピン中はアイコンをアクセント色にし、うっすら背景を敷く
  (ホバー色より弱い固定背景)。実装はコードビハインドで Foreground / Background を
  切り替える (トグルボタン化はしない。既存ヘッダーボタンと同じ Button のまま)。
- ツールチップは状態で切替: 未ピン時「ピン止めして開いたままにする」/ ピン中
  「ピン止めを解除」。Strings.resx (ja) と Strings.en.resx (en) に追加
  (en: "Keep the shelf open" / "Unpin the shelf")。

## 動作

- **ピン中は自動格納のカウントダウンを一切起動しない。** 判定は既存の純粋関数
  `ShelfRetract.ShouldArm` に `bool pinned` 引数を追加して一元化する:
  `isVisible == false` → false (従来どおり) / `pinned == true` → false /
  それ以外は従来の `!pointerInside || dragOpenGraceActive`。
- ピンした瞬間: 走行中の `_retractTimer` を停止する。
- 解除した瞬間: `ArmRetractIfPointerOutside()` を呼び、ポインタが外なら通常の
  カウントダウンに戻す。
- 安全側の二重ガード: `OnRetractTick` の先頭でもピン中なら停止して return
  (ピン操作とタイマー発火の競合対策)。
- 明示的な閉じる (× ボタン、既存の SlideOut 経路すべて) はピン中も従来どおり効く。
  閉じてもピン状態は解除されない。次にシェルフを開いたときもピン中のままで、
  自動格納しない。

## 永続化

- `AppSettings.ShelfPinned { get; set; } = false;` を追加。
- `App.SetShelfPinned(bool)` を追加 (Settings 変更 → SaveSettings のみ。伝播なし)。
  `PinnedExpanded` と同じ「描画するウインドウ自身が唯一の呼び出し元」パターン:
  ShelfWindow のボタンクリックが自分の見た目とタイマーを更新してからこれを呼ぶ。
- ShelfWindow は設定読み込み時 (ApplySettings / 初期化) に `ShelfPinned` を読み、
  内部状態とボタンの見た目に反映する。

## テスト

- `ShelfRetract.ShouldArm` の既存テストに追加: pinned=true なら
  (pointerInside, dragOpenGraceActive) の全組合せでアームしない。pinned=true でも
  isVisible=false は従来どおり false。pinned=false は既存挙動が変わらない。
- SettingsStoreTests: `ShelfPinned` のデフォルト false / ラウンドトリップ /
  旧 settings.json (キーなし) で false。

## ドキュメント / リリース

- 同梱マニュアル assets/README.html: 自動格納 (格納までの時間) に触れている箇所の近くに
  ピン止めボタンの一文を追加。バージョン表記は v1.5.0 のまま変更しない。
- docs/manual-test-checklist.md: §29 の実機結果 (ユーザー実施・全項目合格、2026-08-24)
  を記録し、§30 としてピン止めの項目を追加:
  1. ピン中はポインタを離しても格納しない (格納までの時間を短くして確認)。
  2. ピン解除でポインタが外なら通常どおり格納する。
  3. ピン中も × で閉じられ、再度開くとピン中のまま格納しない。
  4. ピン状態がアプリ再起動後も保持される。
- `build.ps1` で再ビルドし、`dist\TNDrop-Setup-1.5.0.exe` を同バージョンのまま
  置き換える (バージョン番号・AppId は変更しない)。
