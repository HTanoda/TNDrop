# TNDrop v1.3 設計: フィードバック第 3 弾

日付: 2026-08-22 / 対象: v1.3.0

## 背景 (実機フィードバック)

23-1/23-2 (インストーラー自動クローズ)・20-13 (スクショ取り込み) は実機合格。以下が新規要望・問題:

1. 画像をグループ化すると「画像」バッジの件数が減る (カード数で数えているため)
2. グループ解除が実質発見不能 (端 24px 帯ドラッグのみ・無音失敗・別カード上ではマージ優先)
3. スクショ (クリップボード画像) がグループ化できない (ファイルカード同士のみマージ対象のため)
4. 白い画像の上でホバーアクション (ピン等) が見えない
5. クリック貼り付けが「効かない」ように見えた → 検証の結果、抑止ガード (自アプリ前面/検索フォーカス) の正常動作と判断。診断ログのみ追加
6. ピン留め/非ピン留めの境界が不明瞭
7. 設定画面に OS ライトテーマ由来の黒文字が残る (明示色の指定漏れ)
8. グループ展開 (フライアウト) にサムネイルがない
9. コピーインジケーターの光をもっと目立たせたい

## 決定事項 (ユーザー確認済み)

- **バッジ件数はファイル数で数える**: カードの寄与 = スタックなら Paths.Count、それ以外は 1。
  各フィルタの件数 = そのフィルタに属すカードの寄与の合計。CountAll = サブ合計の不変条件は維持
  (カードは必ず 1 フィルタに属す)。フィルタ表示自体はカード単位のまま。
- **クリップボード画像もグループ化可能に**: 画像カードがマージに参加する時点で、内部保存 PNG
  (blob) を指す単一ファイルカードへ変換してからマージ。ファイル名はドラッグアウト時の命名
  ロジックを再利用 (命名の解決は 1 箇所 — one-resolution ルール)。blob ファイルは blobs\ に
  残し、カード削除時の blob 掃除は「パスが blobs\ 配下のファイル参照」も対象に含める。
- **グループ解除は明示 UI が主経路**: フライアウトのヘッダーに「グループ解除」(全件を個別カード
  に一括で戻す。ピン状態は全子カードへ継承)。各行にホバーで「1 件だけ独立」ボタン。
  端ドラッグ (24px/60px 帯) は隠し操作として存続。帯判定で拒否したとき Info ログ 1 行
  (理由: 帯外 / 受理済みドロップ。パスは出さない)。
- **クリック貼り付けは正常**: 抑止時 (自アプリ前面・検索フォーカス・修飾キー) に理由を Info
  ログ 1 行 (「paste suppressed: <reason>」)。機能変更なし。

## UI 改修 (apple-design スキル準拠で実装時に詳細化)

- **ホバーアクションのピル化**: カードのピン・展開・コピー・削除ボタンを画像の上への直接
  オーバーレイから、カード上端に浮かぶ濃色ピル型ツールバー (角丸・半透明ダーク・影) へ移動。
  一般的な同種ツールと同等。白画像でも常時視認可。ドラッグ開始ジェスチャを妨げないこと。
- **ピン留め境界**: ピン留めセクションに薄い背景ティント + 下端区切り線 + ヘッダー視覚強化。
  折りたたみ (PinnedExpanded) の挙動は不変。
- **フライアウト**: 各行の左に 32px 前後のサムネイル (画像/動画は ShellImaging サムネ、他は
  拡張子アイコン。既存の LRU キャッシュ経路を再利用)。ScrollViewer 追加 (Scrollbars.xaml の
  既存手順コメントに従う)。ヘッダー行 (件数 + グループ解除ボタン) を新設。
- **インジケーター強調**: 4 様式 (ビーコン/バー/パルス/コーナー) 共通で、輝度・サイズ・
  表示時間を控えめに増強 (例: 輝度 +30%、表示時間 1.2〜1.5 倍、パルスは 1 周追加)。
  点滅の攻撃性は上げない (業務環境)。IndicatorEnabled=false のゲートは不変。
- **設定画面の黒文字掃討**: OS ライトテーマ時に SystemColors 既定 (黒) が出る部品を総ざらいし
  明示色化 (CheckBox/RadioButton のグリフと ContentPresenter、ComboBox ドロップダウン項目、
  ツールチップ、Slider)。固定ダークデザインは維持。

## テスト方針

- カウント規則 (寄与=ファイル数): 単独/スタック/混在/全画像スタック/CountAll 不変条件。
- 画像カード変換マージ: 変換後の Kind/Paths/blob 参照、削除時の blob 掃除、ピン継承、
  命名がドラッグアウトと同一関数由来であること。
- SplitAll (グループ解除): 全件展開・ピン継承・件数セマンティクス・blob 参照維持。
- UI (ピル/境界/サムネ/インジケーター/設定色) はプローブ (一時ストア・スクリーンショット)。
  実プロファイル・実クリップボードには触れない。
